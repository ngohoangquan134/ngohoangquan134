# Kết Cấu Việt

Plugin Revit 2022.1–2024 gồm 27 công cụ kết cấu, cốt thép, bản vẽ và khối lượng bằng tiếng Việt.

Xem [hướng dẫn đầy đủ và cách cài](HUONG-DAN.md). Mã nguồn trong `src/`, test tính toán trong `tests/`, build và cài bằng PowerShell trong `scripts/`.

Đã chuẩn bị để build riêng theo từng đời Revit. Kiểm thử trực tiếp trong Revit trên Windows là bước bắt buộc trước khi sử dụng trên dự án.
